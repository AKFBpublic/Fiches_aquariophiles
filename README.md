> Collection de fiches techniques détaillées pour l'aquariophilie, publiées par l'AKFB (Aquaclubs Belgium).

## 📋 À propos

Ce repository contient des fiches d'information scientifiquement documentées sur diverses espèces aquatiques maintenues en aquarium. Chaque fiche inclut :

- 🔬 Taxonomie et nomenclature
- 🌍 Distribution géographique et habitat naturel
- 💧 Paramètres de maintenance (température, pH, dureté)
- 🍽️ Alimentation et comportement
- 🐣 Reproduction et élevage
- 📸 Photographies de référence
- 📚 Références scientifiques

Ces fiches sont conçues pour être utilisées lors d'événements aquariophiles via des QR codes, permettant aux visiteurs d'accéder instantanément à l'information complète sur les espèces présentées.

## 📂 Structure du Repository

```
fiches-aquariophiles/
├── killifishes/              # Killi-poissons (Cyprinodontiformes)
├── cichlides-africains/      # Cichlidés d'Afrique de l'Ouest et Centrale
├── cichlides-americains/     # Cichlidés d'Amérique du Sud et Centrale
├── crevettes/                # Crevettes d'aquarium
├── labyrinthides/            # Poissons à labyrinthe (Anabantoidei)
└── autres/                   # Autres espèces
```

## 🚀 Utilisation

### Accès direct aux fiches

Chaque fiche est accessible directement via une URL stable :

```
https://raw.githubusercontent.com/AKFBpublic/fiches-aquariophiles/main/[categorie]/[Nom_espece].pdf
```

**Exemple :**
```
https://raw.githubusercontent.com/AKFBpublic/fiches-aquariophiles/main/killifishes/Aphyosemion_australe.pdf
```

### Via QR Code

Les fiches sont accessibles via des QR codes générés automatiquement lors des événements aquariophiles (bourses, expositions, visites de clubhouse).

### Téléchargement

Pour télécharger toutes les fiches :

```bash
git clone https://github.com/AKFBpublic/fiches-aquariophiles.git
```

## 🤝 Contribution

### Pour les membres AKFB

Les fiches sont générées et publiées via l'application **Aquarium Manager** développée par le club. Si vous souhaitez contribuer :

1. Contactez le responsable de votre section
2. Préparez les informations scientifiques documentées
3. Utilisez l'application pour générer et publier la fiche

### Pour les autres clubs aquariophiles

Nous encourageons la collaboration inter-clubs ! Si vous souhaitez :

- Utiliser nos fiches pour vos événements
- Contribuer de nouvelles fiches
- Signaler des erreurs ou suggestions d'amélioration

Contactez-nous : **info@aquaclubs.be**

## 📊 Versioning

Chaque modification de fiche est tracée via Git, permettant :

- Historique complet des révisions
- Identification des auteurs et modifications
- Possibilité de revenir à une version antérieure
- Transparence totale sur l'évolution des contenus

Pour consulter l'historique d'une fiche, cliquez sur le fichier puis sur "History" dans l'interface GitHub.

## 🔍 Recherche

Pour trouver une fiche spécifique :

1. Utilisez la barre de recherche GitHub (touche `/`)
2. Recherchez par nom scientifique ou nom commun
3. Filtrez par catégorie en naviguant dans les dossiers
